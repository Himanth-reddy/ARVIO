Step by step

Get your first source working.

  1. Check the address on this device

    Open the server in a browser on the device you will use. Include its port and reverse-proxy path if needed. A server that works on your PC may still be unreachable from your TV or a hosted browser app.

  2. Open Settings → Home Server

    Choose the server type. For Jellyfin or Emby, enter the address and your own credentials using the connection form. For Plex, use the provided sign-in flow and select an available server.

  3. Test and save the connection

    Wait for the connection result, then select the libraries you want to show. A normal account can only see libraries shared with that account; admin access is not needed for ordinary browsing.

  4. Open Library → Homeserver

    Select a server and a library. Start with a title you know exists there. Connect additional servers separately so you can tell where each library comes from.

  5. Choose a suitable media version

    Open the title and inspect Sources. Your server can expose multiple versions. Choose a format your device can play; seeing a library does not prove that every file can be decoded.

Useful answers

Before you get stuck.

Why does login fail?

Check the full address, port, username and password. For Jellyfin 12, use an ARVIO build with modern authentication support. A working website login does not guarantee that you entered the correct API address.

The library loads, but playback fails. What next?

Check item permissions, media URL reachability and format support on this device. Try the same item in the server’s own client to narrow down the problem.

Can hosted ARVIO Web reach my private server?

Do not assume it can. Hosted API requests and browser playback have different network restrictions. Local addresses, VPN routing, HTTPS and cross-origin rules can affect access. Do not disable server authentication to make a connection work.

Does ARVIO move or merge the files?

No. Your server remains responsible for its files, permissions and library. ARVIO displays the libraries you are allowed to access.
